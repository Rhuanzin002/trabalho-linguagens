# Fala, Internet!

Site de uma página sobre a linguagem nas redes sociais: abreviações, emojis, memes e interpretação do tom das mensagens.

## Abrir localmente

Abra `index.html` em um navegador.

## Publicar com GitHub Pages

Crie um repositório chamado `trabalho-linguagens`, envie estes arquivos e, em **Settings → Pages**, selecione a branch `main` e a pasta `/ (root)`.
